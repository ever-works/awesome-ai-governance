- [Asqav](https://github.com/jagmarques/asqav-sdk) - Python and TypeScript SDK that writes hash-chained receipts for agent decisions. Cloud-issued receipts are signed server-side with ML-DSA-65, so the agent never holds that key; locally signed receipts use Ed25519 or ES256. Receipts verify offline, and cloud receipts also through a public endpoint without an account. Adapters for LangChain, CrewAI, LlamaIndex, Haystack, Strands, smolagents and the OpenAI Agents SDK. - [cA2A (Confidential A2A)](https://github.com/agentrust-io/ca2a) - A profile for the Agent2Agent (A2A) protocol, which agents use to hand work to each other. Reuses the delegation rules from Agent Manifest and the TEE and policy building blocks from cMCP. Python, developer preview; installable with pip install ca2a-runtime.
