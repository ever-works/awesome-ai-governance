## Overview

AI Explainability 360 (AIX360) is an open-source toolkit from IBM that provides a comprehensive suite of algorithms for explainable AI. It supports interpretability across multiple data types including tabular, text, image, and time series data.

## Features

- Extensive collection of explainability algorithms
- Support for tabular, text, image, and time series data
- Interpretable models and post-hoc explanation methods
- Metrics for evaluating explanation quality
- Python library with extensible architecture
