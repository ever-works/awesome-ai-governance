## Overview

SourceryKit verifies agent outbound requests and MCP handoffs using zero-knowledge proofs.

## Features

- Zero-knowledge proof verification
- Hooks into HTTP libraries
- Logs every outbound call
- Blocks endpoints not on trusted allow-list
- Verifies against source of truth
- Python
- BSL 1.1 (source-available)
- Hosted backend for proof and source-of-truth check

## Deployment

Self-hosted / hosted backend
