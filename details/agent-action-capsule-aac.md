## Overview

Agent Action Capsule (AAC) is an open SCITT statement profile for recording and verifying what an AI agent did. Each action is sealed into a content-addressed, offline-verifiable capsule that a third party can check without calling the operator.

## Features

- Open SCITT statement profile
- IETF draft-mih-scitt-agent-action-capsule
- Content-addressed, offline-verifiable capsules
- JCS/RFC 8785 canonicalization
- Third-party verification without calling the operator
- Reference library, test vectors, and standard site
