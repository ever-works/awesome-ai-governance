## Overview

Practical AI Act is an open-source reference implementation of a high-risk AI system according to Chapter III of the EU AI Act, built on an open-source ML pipeline as part of the Bavarian AI Act Accelerator.

## Features

- High-risk AI system reference implementation
- Chapter III compliance
- Open-source ML pipeline
- Bavarian AI Act Accelerator project

## Pricing

Free and open-source.
