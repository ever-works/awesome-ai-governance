## Overview

agentest is an offline, deterministic testing tool for AI agents that reads OpenTelemetry GenAI traces, A2A AgentCards and MCP tool lists.

## Features

- Offline testing
- Deterministic tests of what an AI agent actually did
- Reads OpenTelemetry GenAI traces
- Reads A2A AgentCards
- Reads MCP tool lists
