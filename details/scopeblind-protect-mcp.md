## Overview

ScopeBlind protect-mcp is a security gateway for MCP servers.

## Features

- Cedar policy enforcement (AWS Cedar via WASM)
- Ed25519-signed decision receipts
- Issuer-blind spending authority (VOPRF)
- Multi-agent swarm tracking
- Merged into AGT (Microsoft Agent Governance Toolkit)

## Deployment

Self-hosted
