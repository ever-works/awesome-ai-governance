## Overview

DiCE (Diverse Counterfactual Explanations) is a Python library for generating diverse counterfactual explanations for machine learning models. Part of the Interpretability/Explicability subsection.

## Features

- Counterfactual explanations
- Diverse explanation generation
- Model interpretability
