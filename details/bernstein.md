## Overview

Bernstein is an open-source AI agent governance tool. Governance rules are written declaratively, and Bernstein enforces them while producing verifiable, replayable evidence records of what agents did.

## Features

- Declarative governance rule definition for AI agents
- Runtime enforcement of governance rules
- Verifiable, replayable execution records
- CLI, MCP, hooks, and supported proxy paths
