## Overview

The AI Agent Trace Schema is an open JSON Schema that normalizes AI-agent runtime events — including tool calls, human interventions, errors, and deployment changes — into a common format suitable for compliance evidence. It includes converters for OpenTelemetry and LangSmith exports.
