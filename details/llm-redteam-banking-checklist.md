## Overview

llm-redteam-banking-checklist is an Apache-2.0 release gate for LLM red-team findings in banking.

## Features

- Release gate for LLM red-team findings in banking
- Scores findings across nine harm categories
- Seven categories mapped to OWASP LLM Top 10 2025
- Checks five go/no-go gates
- Fails pytest or GitHub Actions job when a gate is red
- Sends no prompts and calls no model
