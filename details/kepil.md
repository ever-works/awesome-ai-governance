## Overview

Kepil is an AGPL-3.0 Python toolkit for agent-version passports, per-job mandates, and a gateway that checks submitted actions against permissions, spending limits, and expiry.

## Features

- Agent-version passports
- Per-job mandates
- Gateway for checking submitted actions against permissions
- Spending limits and expiry enforcement
- Passport construction rejects highest autonomy class
- Python standard library
