## Overview

solvi is an Apache-2.0 Python runtime whose Guard checks each agent tool call against a catalog, argument types and policy rules.

## Features

- Python runtime
- Guard checks each agent tool call against catalog, argument types and policy rules
- Allows, denies or escalates tool calls to a person
- Hash-chained trace of every decision
- Offline replay capability
