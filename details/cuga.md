## Overview

CUGA is an IBM Research generalist agent harness that provides five configurable policy types for governing agent behavior.

## Features

- Five configurable policy types: Intent Guard, Playbook, Tool Approval, Tool Guide, Output Formatter
- Human-in-the-loop approval of tool calls
- Generalist agent harness
