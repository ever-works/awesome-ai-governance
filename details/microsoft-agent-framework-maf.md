## Overview

Microsoft Agent Framework (MAF) is a multi-agent orchestration framework for Python and .NET with migration paths from Semantic Kernel and AutoGen.

## Features

- Multi-agent orchestration framework
- Python and .NET support
- Migration paths from Semantic Kernel and AutoGen
- Human-in-the-loop workflow steps
- Checkpointing
- Built-in OpenTelemetry tracing
