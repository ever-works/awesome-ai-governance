## Overview

Provenza is a self-hosted AI and agent governance control plane.

## Features

- Discovers AI use and AI agents
- Endpoint agent for Linux, Windows and macOS
- Browser extension
- DNS and proxy logs
- Team- and agent-level policy enforcement
- Human approvals
- Kill switch
- Hash-chained audit log with signed Merkle checkpoints

## Deployment

Self-hosted
