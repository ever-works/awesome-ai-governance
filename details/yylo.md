## Overview

YYLO is a command-line orchestrator for governing coding-agent repository changes.

## Features

- Freezes protected target SHA per task
- Dedicated branch/worktree
- Typed task, validation, merge, and release-readiness boundaries
- Risk-based review merge queue
- Stops as REVIEW_FINDINGS_EXHAUSTED
- Declared receipt hashes and terminal manifests
- Orchestrates Pi and Codex subagents
- npm package: @yylo/cli

## Deployment

Self-hosted
