## Overview

npmscan is a read-only MCP server and agent skills that reports security issues for npm packages an AI agent is about to install.

## Features

- Read-only MCP server and agent skills
- Reports confirmed malware
- Reports known vulnerabilities
- Reports maintainer takeovers
- Reports install scripts for npm packages
- PASS/WARN/FAIL verdict on dependency changes
- Does not block installs itself
