## Overview

HOL Guard is a local-first runtime control for AI coding agents.

## Features

- Evaluates shell, file, MCP, plugin/skill, and package actions before side effects
- Allow/block/approval policy
- Local security receipts
- Optional cloud with shared policy and evidence sync
- Apache-2.0 licensed

## Deployment

Local-first (self-hosted), optional cloud
