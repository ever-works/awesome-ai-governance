## Overview

The OWASP AI Security Verification Standard (AISVS) is a verification-controls standard with 14 chapters covering training data, input validation, model lifecycle, infrastructure, access control, supply chain, model behavior, memory/embeddings, autonomous orchestration (C9), MCP security (C10), adversarial robustness, privacy, monitoring, and human oversight. v1.0 released at OWASP Global AppSec EU Vienna on 24 June 2026.
