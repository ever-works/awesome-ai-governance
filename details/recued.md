## Overview

Recued is a self-hosted server between AI agents and personal data systems.

## Features

- Agent connections over MCP via contract
- Tool allowlisting per agent
- Every call gated and logged before execution
- Writes and deletes wait for owner approval
- Per call, batch or session approval
- AGPL-3.0 licensed

## Deployment

Self-hosted
