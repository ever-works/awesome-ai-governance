## Overview

Ironheights is an Apache-2.0 local scanner for OpenClaw/ClawHub agent skills that flags prompt injection, credential reads, remote-exec installs and persistence before install.

## Features

- Local scanner for OpenClaw/ClawHub agent skills
- Flags prompt injection
- Flags credential reads
- Flags remote-exec installs
- Flags persistence before install
- Records integrity baseline to flag later changes
