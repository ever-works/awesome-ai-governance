## Overview

agent-trace is an MIT-licensed TypeScript verifier for Python-generated, hash-chained agent journals.

## Features

- TypeScript verifier
- Python-generated hash-chained agent journals
- Sequence checking
- Chain linkage verification
- Record hash verification
- Reports first failing record's sequence number
- Developed in the ProofByte monorepo
