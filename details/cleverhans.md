## Overview

CleverHans is an open-source library for adversarial machine learning. It provides implementations of adversarial attack algorithms and tools for benchmarking the robustness of machine learning models against adversarial examples.

## Features

- Adversarial attack algorithms (FGSM, BIM, JSMA, Carlini-Wagner, DeepFool, etc.)
- Adversarial training defenses
- Model robustness benchmarking utilities
- Support for TensorFlow and other ML frameworks
- Python library with academic research focus
