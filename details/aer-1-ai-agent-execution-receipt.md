## Overview

AER-1 (AI Agent Execution Receipt) is an IETF Internet-Draft that defines a verifiable receipt for each AI agent tool call using SHA-256 over canonical bytes, chained per job.

## Features

- Verifiable receipt for each AI agent tool call
- SHA-256 over exact saved output bytes in canonical_bytes
- Chained per job for tamper detection
- Open-source kit and conformance corpus (143 vectors, 146 checks)
- Verifier at zambo.dev/verify
