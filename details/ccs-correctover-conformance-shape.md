## Overview

CCS provides cryptographic runtime-verification receipts for agent tool calls.

## Features

- Ed25519 (RFC 8032) over RFC 8785 JCS canonical JSON
- Prev-receipt hash chaining
- MIT-licensed
- Language-neutral conformance vectors
- 10 vectors covering valid, tampered, algorithm-substitution, [redacted secret], and chain-linked cases
