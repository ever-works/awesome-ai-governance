## Overview

NocoBase is an open-source platform for building, running, and evolving business systems with AI. AI agents write code and perform work, NocoBase provides the foundation and governance layer, and people make the decisions.

## Features

- Open-source business system platform
- AI agent integration with code generation
- Governance foundation for AI-driven workflows
- Self-hosted deployment
- Human-in-the-loop decision authority

## Pricing
