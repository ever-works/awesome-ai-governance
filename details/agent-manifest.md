## Overview

Agent Manifest signs all 10 parts of an agent deployment into one record.

## Features

- Signs 10 parts: system prompt, policy bundle, model identity, tool schemas, RAG corpus, memory baseline, decision trace, A2A delegation chain, build provenance, HITL approvals
- Detects any later change to any part
- Signed hardware report (attestation) from TPM, AMD SEV-SNP or Intel TDX
- Four conformance levels
- Compliance mappings: EU AI Act, DORA, GDPR, HIPAA
- 197 conformance tests
- Python
- Developer preview
