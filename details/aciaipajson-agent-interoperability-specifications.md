## Overview

ACI/AIP/AJSON are open standards for agent interoperability and governance. They comprise the Agent Communication Interface (ACI), Agent Interaction Protocol (AIP), and Agent JSON (AJSON) — machine-readable agent manifests for discovery, delegation, and governance.
