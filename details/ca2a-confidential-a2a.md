## Overview

cA2A is a Confidential A2A protocol profile for agent-to-agent work handoffs.

## Features

- Profile for Agent2Agent (A2A) protocol
- Delegation: same or less authority than received
- Hardware check of other agent's runtime
- Sealed channel between agents
- Offline-checkable handoff records
- Reuses delegation rules from Agent Manifest
- TEE and policy building blocks from cMCP
- Python
- Developer preview
- pip install ca2a-runtime

## Deployment

Self-hosted
