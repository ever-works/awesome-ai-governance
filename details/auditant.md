## Overview

Auditant is a hosted audit trail for AI agents that provides Python and TypeScript SDKs for recording model and tool calls.

## Features

- Hosted audit trail for AI agents
- Python and TypeScript SDKs (Apache-2.0)
- Emits hash (not payload) of each model and tool call, linked
- Edit or deletion detection
- Synchronous policy check
- Offline verifier (does not need to touch Auditant)
- Commercial, free for 1 agent

## Pricing

Commercial with a free tier for 1 agent. SDKs under Apache-2.0 license.
