## Overview

Scalekit is an agent integration platform that brokers per-user OAuth access to 600+ apps with scoped permissions, serves selected tools to each agent through virtual MCP servers, and records every agent tool call in an audit log.

## Features

- Brokers per-user OAuth access to 600+ apps
- Scoped permissions
- Serves selected tools to each agent through virtual MCP servers
- Records every agent tool call in an audit log
- SIEM streaming on Enterprise
