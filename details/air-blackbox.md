## Overview

AIR Blackbox is an open-source EU AI Act compliance scanner and runtime trust layer for Python AI agents.

## Features

- EU AI Act compliance scanning
- Runtime trust layer for Python AI agents
- HMAC-SHA256 tamper-evident audit chains
- PII detection
- Prompt injection blocking
- Trust layers for LangChain, CrewAI, AutoGen, OpenAI, Google ADK, and Claude Agent SDK
