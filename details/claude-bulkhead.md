## Overview

claude-bulkhead provides pre-tool hooks for coding agents to block destructive shell commands.

## Features

- Pre-tool hooks for Claude Code, Codex, Gemini CLI, Copilot CLI, Cursor
- Matches shell command text against destructive patterns
- Denies destructive commands with safer form
- Not a sandbox (does not see deletes inside scripts)

## Deployment

Self-hosted
