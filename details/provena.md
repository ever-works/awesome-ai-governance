## Overview

Provena is an open-source Python library for tamper-evident audit trails of AI agent context inputs.

## Features

- Tamper-evident audit trails of AI agent context inputs
- Hash-chained logging
- Provenance validation
- Freshness checking
- EU AI Act compliance reporting
- OWASP ASI06 compliance reporting
