## Overview

Mandare is a self-hosted LLM gateway that enforces human-signed per-agent spend mandates and writes every allow and refusal to a hash-chained, witnessable ledger.

## Features

- Self-hosted LLM gateway
- Human-signed per-agent spend mandates
- Hash-chained, witnessable ledger for allows and refusals
- Apache-2.0 libraries, AGPL-3.0 servers
