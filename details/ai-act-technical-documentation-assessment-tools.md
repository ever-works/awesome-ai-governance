## Overview

AI Act Technical Documentation Assessment Tools is an open-source research replication package for using AI to draft Annex IV-compliant technical documentation under the EU AI Act.

## Features

- AI-powered technical documentation drafting
- Annex IV compliance
- Research replication package
- EU AI Act technical documentation support

## Pricing

Free and open-source.
