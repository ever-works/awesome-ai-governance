## Overview

Quilzo is a self-hosted control plane for AI agents whose agent runs, app calls and erasures come as receipts.

## Features

- Self-hosted control plane for AI agents
- Receipts for agent runs, app calls and erasures
- Inclusion proof against a log head
- Ed25519 and ML-DSA signing
- Offline verification against published keys
