## Overview

PIC Standard (Provenance & Intent Contracts) is an open, local-first protocol for pre-execution action gating in AI agents.

## Features

- Pre-execution action gating
- Agent declares intent, provenance, and evidence before high-impact tool calls
- Verifier returns allow or block
- Fails closed on missing or invalid evidence
- Trust Axiom: trust is verifier-derived, not producer-asserted
- Apache-2.0 licensed
- Pre-v1.0 draft
