## Overview

AEGIS by 100monkeys.ai is a self-hosted agent orchestrator currently in beta. It is licensed under AGPL-3.0.

## Features

- Manifest-declared network and filesystem policy enforcement in the orchestrator
- Isolated runtimes for agent execution
- End-to-end tool call verification using the SEAL protocol
- Self-hosted deployment
