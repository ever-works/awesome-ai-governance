## Overview

Agent Passport System is an Apache-2.0 protocol for agent identity, scoped delegation with monotonic narrowing, runtime enforcement, and signed action receipts.

## Features

- Agent identity protocol
- Scoped delegation with monotonic narrowing
- Runtime enforcement
- Signed action receipts
- TypeScript and Python SDKs
- Active IETF Internet-Draft (draft-pidlisnyi-aps)
