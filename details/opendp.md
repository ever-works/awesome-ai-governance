## Overview

OpenDP is an open-source library for privacy-aware computations with differential privacy. It provides a framework for constructing, transforming, and executing differentially private data analyses with formal privacy guarantees.

## Features

- Differential privacy transformations and measurements
- Privacy budget tracking and composition
- Support for multiple programming languages (Rust, Python, etc.)
- Formal privacy guarantees with mathematical verification
- Modular architecture for extensible privacy computations
