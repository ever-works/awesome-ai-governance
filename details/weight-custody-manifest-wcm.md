## Overview

Weight Custody Manifest (WCM) is an open specification and Python SDK for model weight decryption key custody.

## Features

- Decryption key released only to workload with matching CPU/GPU attestation
- Short-lived approval
- Record of each release
- Verifies AMD SEV-SNP, Intel TDX, NVIDIA H100 CC evidence
- Apache-2.0 licensed
- pip install weight-custody-manifest
- Pre-1.0
