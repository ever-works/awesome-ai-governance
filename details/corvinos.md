## Overview

CorvinOS is a self-hosted agentic operating system that connects local and cloud models to multiple messaging platforms including Discord, Telegram, WhatsApp, Slack, and Email.

## Features

- Self-hosted agentic OS
- Integration with Discord, Telegram, WhatsApp, Slack, and Email
- Fail-closed GDPR consent gate
- Hash-chained audit log
- Bot-disclosure controls
- Python implementation
