## Overview

Fair Code is a toolkit for auditing real-world-style AI decision systems for algorithmic bias.

## Features

- Audits AI decision systems across criminal justice, hiring, lending, insurance, welfare, hospital readmission, and tenant screening
- Algorithmic bias detection
- Pairs biased baseline with mitigated version
- Measured before/after fairness metrics
