## Overview

agent-security-harness is an open-source adversarial testing framework for autonomous agents, featuring EU AI Act crosswalks for security assessment.

## Features

- Adversarial testing for autonomous agents
- EU AI Act crosswalks
- Red team / blue team agent fabric
- Security assessment

## Pricing

Free and open-source.
