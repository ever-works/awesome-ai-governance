## Overview

Meilynx is an inline proxy for LLM and agent traffic with governance rules.

## Features

- Inline proxy for LLM and agent traffic
- Governance rules per request
- Permits or blocks tools and MCP calls per policy
- Tamper-evident, hash-chained audit trail
- Open-source verifier (meilynx-verify, Apache-2.0)
- Offline verification

## Deployment

Hosted (inline proxy)
