## Overview

scitt-cose is a payload-agnostic IETF SCITT + COSE verification substrate implemented in Python. It verifies Signed Statements and RFC 9162 SHA-256 Receipts with inclusion/consistency proofs, offline.

## Features

- Payload-agnostic IETF SCITT + COSE verification
- Verifies Signed Statements
- Verifies RFC 9162 SHA-256 Receipts
- Inclusion/consistency proofs
- Offline verification
- Free community verify service
