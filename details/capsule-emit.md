## Overview

capsule-emit is the reference implementation of Agent Action Capsule. It provides a one-call emit() producer that seals an action into a capsule, anchors it by default, and ships a ledger-view CLI with thin framework adapters.

## Features

- One-call emit() producer
- Seals actions into capsules
- Anchors by default
- Ledger-view CLI
- Thin framework adapters
