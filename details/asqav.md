## Overview

Asqav is a Python and TypeScript SDK that writes hash-chained receipts for agent decisions.

## Features

- Hash-chained receipts for agent decisions
- Python and TypeScript SDKs
- Cloud-issued receipts signed server-side with ML-DSA-65
- Locally signed receipts use Ed25519 or ES256
- Offline receipt verification
- Cloud receipts verifiable through public endpoint without account
- Adapters for LangChain, CrewAI, LlamaIndex, Haystack, Strands, smolagents and OpenAI Agents SDK
