## Overview

agent-evidence-vectors is an Apache-2.0 project providing conformance corpora and reference verifiers for proposed agent-execution evidence predicates.

## Features

- Conformance corpora for agent-execution evidence predicates
- Reference verifiers
- SCITT/COSE carriage support
- Evidence-binding profiles
