## Overview

YBK is a self-hosted control plane for MCP servers, skills, agents and AI apps.

## Features

- Per-tool permission points
- Lifecycle state machine
- Gray deploys
- Dependency-aware impact preview
- Usage attributed per department × agent × skill
- Append-only audit log
- Single process by default
- Multi-node HA designed but not shipped

## Deployment

Self-hosted
