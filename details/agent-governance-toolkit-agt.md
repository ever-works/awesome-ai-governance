## Overview

Agent Governance Toolkit (AGT) is a production governance layer for autonomous agents developed by Microsoft.

## Features

- Policy enforcement kernel (<0.1ms p99)
- Execution rings (Ring 0-3)
- Cryptographic Merkle audit logs
- Integrations: LangChain, CrewAI, AutoGen, Google ADK
- Hardware-attested enforcement via cMCP
- Supports Python, .NET, and Rust

## Deployment

Self-hosted
