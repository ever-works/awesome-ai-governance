## Overview

EU AI Act MCP Server is an open-source MCP server providing compliance tools for EU AI Act, including risk classification, prohibited practice checks, and transparency disclosures.

## Features

- Risk classification
- Prohibited practice checks
- Transparency disclosures
- MCP server protocol
- EU AI Act compliance tools

## Pricing

Free and open-source.
