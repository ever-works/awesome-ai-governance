## Overview

sentinel-scan-cli is a free, open-source CLI and MCP server that scans MCP manifests and LLM apps for security issues.

## Features

- Free, open-source CLI and MCP server
- Scans MCP manifests and LLM apps
- Detects tool poisoning
- Detects prompt injection
- Detects rug-pulls
- OWASP LLM Top 10-mapped findings
