## Overview

TRACE is an open specification and Python SDK for signed receipts of agent runs.

## Features

- Signed receipts of agent runs
- Record of model, runtime, policy version, tool calls
- Offline verification without contacting operator
- Separately verified attestation for hardware proof
- Built on IETF RATS (RFC 9334), EAT (RFC 9711), SCITT, SLSA, SPIFFE
- Series of LF Projects
- AAIF Sandbox proposal
- Spec v0.2
- Python SDK
