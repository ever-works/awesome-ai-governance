## Overview

ai-act-conformity-pack is an open-source Python CLI tool that generates an Annex IV technical-documentation skeleton (covering Articles 11-15) from a YAML model card for EU AI Act compliance.

## Features

- Annex IV technical documentation skeleton generation
- Articles 11-15 coverage
- YAML model card input
- Python CLI
- MIT licensed
