## Overview

OrcaReplay records an AI agent's run from outside the process — the verbatim model requests and responses, every tool call with its arguments, shell exit codes and file changes — and replays it offline so the recorded run can be re-executed and inspected rather than reconstructed from logs.

## Features

- External process recording of AI agent runs
- Verbatim model requests and responses
- Tool call recording with arguments
- Shell exit code and file change tracking
- Offline replay for inspection
- Local files only, nothing uploaded

## Notes

Makes no compliance claim and has no tamper-evidence; produces the underlying record, not an attestation about it.
