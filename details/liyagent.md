## Overview

Liyagent is an agent platform with governance features, available hosted or self-hosted.

## Features

- Agents run as requesting user
- Tool calls checked against agent and user permissions
- Agent writes wait for human approval by default
- Per-agent budgets
- Hash-chained audit log
- Ed25519-signed evidence bundles
- Apache-2.0 CLI
- Offline audit verifier

## Deployment

Hosted or self-hosted
