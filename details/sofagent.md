## Overview

sofagent is an open-source harness for governing AI coding agents.

## Features

- Ontology-driven workflows
- 28 commit-time audit rules over git diffs
- Secrets detection
- Out-of-scope edits detection
- Blind modifications detection
- Prompt injection detection
- HMAC-signed tamper-evident audit history
- MCP tools for governance aggregation

## Deployment

Self-hosted
