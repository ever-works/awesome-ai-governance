## Overview

Hermes Jailbench is a deterministic jailbreak regression battery that runs repeatable attacks against an LLM endpoint.

## Features

- Deterministic jailbreak regression battery
- Runs repeatable attacks against LLM endpoints
- Scores refusal, partial, and compliance outcomes
- Cross-run comparison
