## Overview

arifOS is an AGPL-3.0 governance kernel for MCP agents.

## Features

- Evaluates proposed actions against policy floors F1-F13
- Seven wire verdicts: SEAL, HOLD, SABAR, PARTIAL, PROVISIONAL, HOLD_888, VOID
- Hash-chained decision ledger
- pip install arifos

## Deployment

Self-hosted
