## Overview

Allowly provides hosted policy decisions and signed receipts for AI-agent actions.

## Features

- Hosted policy decisions
- Signed receipts for AI-agent actions
- Offline receipt verification with Ed25519 keys
- Open-source Python and TypeScript verifiers
- CC BY 4.0 specification
- Interoperability map

## Deployment

Hosted (cloud)
