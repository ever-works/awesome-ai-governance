## Overview

Aident Loadout is a hosted MCP server and CLI that runs agent tool calls through a credential vault.

## Features

- Hosted MCP server and CLI
- Credential vault: agents get results, not raw API keys
- Shows cost of each action before it runs
- Audit log of what ran, where it came from, whether it succeeded and what it cost
- MIT-licensed client skill

## Pricing

Commercial with a free pay-as-you-go tier.
