## Overview

Google Sovereign Agent Mesh (SAM) is an agent-mesh project that provides cryptographic node identities, authenticated peer connections, discovery, authorization policies, and MCP sidecar routing. Note: The repository states that it is not an officially supported Google product.

## Features

- Cryptographic node identities
- Authenticated peer connections and packets
- Discovery and authorization policies
- MCP sidecar routing
- Apache-2.0 licensed
