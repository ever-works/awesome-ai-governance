## Overview

LightAgent is a Python agent framework that provides narrowing-only security contexts, scoped capability gates, durable human approvals, and application-owned verification.

## Features

- Narrowing-only security contexts
- Scoped capability gates
- Durable human approvals
- Application-owned verification
- Immutable DAG artifact publishing
