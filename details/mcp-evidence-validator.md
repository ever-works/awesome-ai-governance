## Overview

mcp-evidence-validator is a reference implementation of SHA-256 evidence chains for MCP agents.

## Features

- SHA-256 evidence chains for MCP agents
- Verifies declared tool contracts against observed runtime behavior
- Declared vs observed comparison
- Apache-2.0 licensed
- OpenSSF Best Practices badge
