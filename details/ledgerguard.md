## Overview

LedgerGuard is an Apache-2.0 TypeScript runtime between an AI agent and a PostgreSQL system of record.

## Features

- Deterministic allow/deny/require-approval policy
- Approvals bound to plan id and version
- Typed allowlisted corrections instead of free SQL
- Execute, verify and commit in one transaction
- Persisted idempotency key
- Pre-1.0
- Postgres only

## Deployment

Self-hosted
