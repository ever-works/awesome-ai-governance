## Overview

PySyft is an open-source library from OpenMined for secure and private deep learning. It enables federated learning, secure multi-party computation, and differential privacy for training machine learning models on distributed data without sharing raw data.

## Features

- Federated learning for distributed model training
- Secure multi-party computation (SMPC)
- Differential privacy integration
- Encrypted computation and remote execution
- Support for PyTorch, TensorFlow, and other frameworks
- Python library with PyGrid and PyNode infrastructure
